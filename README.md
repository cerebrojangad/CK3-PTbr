# CK3-PTbr
tradução do crusader kings 3 pra pt-br


Só colar a pasta do zip dentro de pasta base do jogo. Para o jogo ficar em português, escolha a língua "Espanhol" nas configurações e reinicie o jogo.

A tradução base não é minha. Peguei uma que roda na internet e que tava bastante quebrada e corrigi isso. Não sei o nome do autor pra dar os créditos então se alguem souber, avisa.
Além disso, estou aos poucos traduzindo o que encontro ainda em espanhol e/ou inglês então vale sempre ficar de olho aqui pra pegar o arquivo mais atualizado. Se quiser ajudar, será bem vindo.
Ainda nao tá 100% mas acho que uns 95% deve estar.
